PUBLICATION PACKAGE READY

Two quick commits. Then you're live.

The updated resource index has been generated from the current library. Publishing requires your authorised GitHub account.

  1. If you selected a PDF, upload it to the repository's materials/ folder. Keep the filename exactly as selected.
  2. Copy the generated JSON and replace the repository's resources.json contents. Commit the changes to main.
  3. GitHub Pages rebuilds the site from your committed files. Refresh the public library after the Pages deployment completes.
