02 / THE METHOD

A practice paper
should make you think.

Not every question needs to be unfamiliar. But good practice should expose the difference between remembering a method and understanding it.
01

Attempt it properly.

Set a timer. Work without looking at solutions. Treat each line of reasoning as part of the answer.

↗
02

Find the exact gap.

Was the difficulty conceptual, algebraic, or a careless mistake? Identify the point where the reasoning broke down.

∴
03

Return to the question.

Redo it later, without notes. The goal is not to remember the solution—it is to be able to reconstruct it.
